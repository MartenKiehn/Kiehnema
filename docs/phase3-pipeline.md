# Phase 3 – LangGraph pipeline (Claude Opus 5.5 on Bedrock)

```bash
uv run python -m app.pipeline start https://www.example.com/ --duration 30 --description "goal, audience, tone"
uv run python -m app.pipeline status <job_id>
uv run python -m app.pipeline resume <job_id> --feedback "make the hook punchier"
uv run python -m app.pipeline resume <job_id> --edit hook-headline="Neuer Text"
uv run python -m app.pipeline resume <job_id> --approve        # renders both MP4s
```

```
crawl → brand → distill → concept → compose → check ─┬─> fix → check   (≤ 3 automatic rounds)
                                                      └─> keyframes → qa ─┬─> fix (major issues, once)
                                                                           └─> review ⏸ ─┬─> fix (edits / feedback)
                                                                                          └─> render → END
```

| Step | What happens | Model call |
|---|---|---|
| crawl / brand | Phase 2 (SSRF-guarded crawl, brand kit, brand board) | – |
| distill | company profile; every fact carries a verbatim quote + source URL; quotes are verified against the crawl, unverifiable facts are dropped | structured, effort low |
| concept | storyboard (scenes, copy, visual idea, palette, cues, music); validated in code: beat-grid timing, contiguous scenes, every claim backed by fact ids, reading time, assets, client-logo permission, cue rules – violations go back to the model (≤ 3 attempts) | structured, effort medium |
| compose | the model writes composition.html/css/js against the harness contract (`docs/harness-contract.md`) with the golden example in the cached system prompt; manifest and theme are generated by code | streamed text, effort medium, 100k max tokens |
| check | static lint (no network/timers/eval/external URLs/CSS animation, all text ids present) + runtime checks (contract, determinism, readability, layout in both formats) | – |
| fix | search/replace edits (or whole files) for lint/check problems, QA issues or reviewer feedback; same system prompt as compose → cache hit | streamed text, effort low |
| keyframes / qa | one frame per scene and format at its reading moment; art-director review on the images | structured with images, effort medium |
| review | LangGraph `interrupt()`: approve, edit copy (`data-text-id` → new text, kept in sync with the storyboard) or free-text feedback | – |
| render | music from the registry + 4:5 and 9:16 MP4 (Phase 1) | – |

State is checkpointed in `data/jobs.sqlite` (one thread per job), artefacts live in `data/jobs/<id>/`:
`crawl/ brand/ profile.json concept.json composition/ site/ check.json keyframes/ qa.json logs/ renders/ status.json llm.jsonl`.
`status.json` carries the step history, live progress (streamed characters while code is written) and the
running cost estimate.

## Live run 1 – www.they-consulting.de, 30 s
Brief: "LinkedIn/Instagram ad. Make clear right at the start that nothing is built for the drawer here –
only useful AI that works in daily business."

| Step | Time | Input tok | Output tok | Notes |
|---|---|---|---|---|
| crawl + brand | ~45 s | – | – | 20 pages |
| distill | 34 s | 42,004 | 3,588 | 30 facts, 0 dropped |
| concept | 55 s | 7,470 | 4,930 | 7 scenes, valid on the first attempt |
| compose | 699 s | 24,121 (cache write) | 58,521 | **passed every check on the first attempt** – no automatic fix round |
| qa | 26 s | 13,313 | 1,441 | approved, 4 minor notes |
| review feedback → fix | 64 s | 45,096 (18,905 cache read) | 6,199 | 3 reviewer requests, 5 edits + 1 file |
| render | ~5 min | – | – | 2 × 900 frames, −14.3 LUFS |

Start → review: 14.4 min. Estimated cost (Anthropic list price; Bedrock billing may differ): **$2.00**.

Learnings applied: at most one drop/outro cue (validator), live progress during code generation,
current step tracked in the graph state. QA flagged a "straight closing quote" that is actually the correct
U+201C glyph drawn wedge-shaped by Chivo Black – a font quirk, not a code bug.

### Brand-extraction bugs found by run 2 (fixed, with tests)
1. Logos inlined as `data:image/svg+xml` `<img>` (common with bundlers) were filtered out by the crawler →
   data URLs are now kept (size-limited), decoded locally (no network) and sanitised like any SVG.
2. A weak logo guess (a contact portrait) was used as "logo" → candidates below a confidence score are
   rejected ("better no logo than a wrong one"); header text wordmarks are extracted as typography instead.
3. Small logo colours were lost by k-means (the yellow mark) and duplicates appeared → replaced by a
   deterministic colour histogram with near-duplicate merging; Atlas now yields #164656 / #ea5837 / #f7b85a.
For the running job the brand kit was refreshed and the composer fixed the video in one feedback round.
