# Video request log

Design generated with the built-in Imagegen tool before implementation. Reference: [concept.png](concept.png).

Implemented in Backstage → Video requests for Directors only. Each entry exposes only the current username and request time (UTC). New accepted URL and file requests are recorded from this feature onward; existing encrypted jobs are not inspected or backfilled. Deleting a video preserves its entry; deleting an account removes its entries.
