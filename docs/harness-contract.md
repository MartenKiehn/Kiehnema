# Composition harness contract

This is the contract a composition (hand-written or generated by Claude Opus 5.5) must follow.
It is the basis of the code-generation prompt in Phase 3. Reference implementation:
`examples/they/` (30 s, 7 scenes, passes every check).

## Files

| File | Content |
|---|---|
| `manifest.json` | `title`, `language` (e.g. `de`), `duration` (s), `music` {`bpm`, `progression`, `outro_progression`, `energy`: calm\|medium\|high}, free-form `scenes` / `marks` the JS may read |
| `theme.json` | `colors` {name: hex/rgb} → CSS vars `--brand-<name>`; `fonts` [{family, src, role: display\|body}] → `@font-face` + `--font-display` / `--font-body` |
| `composition.html` | markup inserted into `#stage` (no `<script>`, no external URLs) |
| `composition.css` | styles; layout must work for **both** formats via `.fmt-feed` / `.fmt-story` on `#stage` |
| `composition.js` | `MG.composition((ctx) => { … })` – builds the paused timeline `ctx.tl` |
| `assets/` | local logo / images / fonts only |

`app.harness.build.build_site()` validates manifest and theme (colours, names and paths are
whitelisted) and produces a site: `index.html theme.css harness/ composition/ assets/`.

## Stage and formats
- `#stage` is 1080×1350 (`feed`, 4:5) or 1080×1920 (`story`, 9:16). `ctx.FORMAT`, `ctx.W`, `ctx.H`, `ctx.isStory`.
- Timing must be identical in both formats; only layout may differ (checked: `format-divergence`).

## ctx API
| Member | Purpose |
|---|---|
| `tl` | the one paused GSAP timeline – **everything** visual is a tween/set on it |
| `gsap`, `$`, `$$` | GSAP and query helpers |
| `scene(id, start, duration, {visibleFrom, visibleUntil, whoosh})` | registers element `#id` as a scene, toggles its visibility; returns `{T, D, end, el, sel}` |
| `words(selOrEls, at, stagger = 0.045, duration = 0.6)` | word-by-word reveal of `.split` text |
| `fadeUp(sel, at, extra)` / `exitUp(sel, at)` / `EXIT` (0.35 s) | standard enter / exit |
| `stroke(path)` | prepares an SVG path for a draw-on tween (`strokeDashoffset → 0`) |
| `cue(t, type, opts)` | sound cue for the music engine (table below) |
| `split(el)` | word masks for text created dynamically (`.split` elements are split automatically before the build function runs) |
| `manifest`, `theme`, `RENDER` | data |

## Rules (enforced by `app/checks/runtime.py`)
1. **Deterministic:** no CSS animations/transitions (disabled in render mode), no timers,
   `requestAnimationFrame`, `Date.now()`/`performance.now()`; `Math.random` is seeded.
   Frames must be identical regardless of seek order or page instance.
2. **No network:** CSP `connect-src 'none'`, `self` only; any other origin is blocked and reported.
3. **Timeline coverage:** scenes start at 0 and cover the whole duration (gaps ≤ 0.3 s).
4. **Readability:** every visible text carries a unique `data-text-id`. From first appearance to
   leaving, a text needs ≥ `0.5 s + words / 4` (error below 75 %) and must be completely visible
   (opaque, unblurred, all words revealed) for ≥ 0.8 s.
5. **Layout:** at its mid-hold time a text lies fully inside the frame (error) and ≥ 24 px from the
   edge (warning), in both formats.
6. **Cues** must use the known types and lie inside the duration.

## Sound cues (`app/music/synth.py:CUE_TYPES`)
| Type | Meaning |
|---|---|
| `drop` | drums + bass start (bar one); usually with `riser` + `impact` |
| `groove` | claps + ghost hats join (default: first cut after the drop) |
| `arp` | arpeggio starts (default: two bars before the drop) |
| `outro` | drums stop, harmony resolves to `outro_progression` |
| `stop` {until} | music ducks (dramatic pause) |
| `riser` {length, gain} | noise riser *ending* at t |
| `impact` {gain} | sub boom + crash |
| `whoosh` | transition whoosh – added automatically at every scene start except t = 0 and scenes starting on `drop`/`outro`; disable per scene with `scene(…, {whoosh: false})` |
| `swoosh`, `thud`, `slide`, `tick` {until} | foley-style accents |
| `chime`, `bell` {note}, `bells` {notes, step} | positive accents (MIDI notes) |

Kick drums leave a one-beat gap before every automatic whoosh cut. Choose scene starts on the
beat grid (60 / bpm) so cuts land on beats.
