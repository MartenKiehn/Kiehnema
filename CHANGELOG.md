# Kiehnema change log

User-facing changes, newest version first. Each version has a `## MAJOR.MINOR.PATCH`
heading followed by plain-text `- Change.` bullets. Release notes are taken from
this file. Versions newer than the installed version are not shown in the app.

## 0.2.2

- Show image thumbnails beside selected PNG, JPG and WebP files in the video brief.

## 0.2.1

- Create videos from uploaded images and PDFs as well as websites, with a source selector and private source downloads.
- Upload up to 10 files totalling 100 MB; a single file can use the full allowance. PDFs have no page-count limit, with an in-app confirmation before processing more than 20 pages in total.
- Read native PDF text and additional text inside scanned images together, retaining page references for reviewing the resulting facts.
- Use individually extracted PDF images in video scenes, with motif descriptions, preserved transparency and duplicate-image detection. Full-page references remain available for scans and layouts.
- Follow file-processing progress, review source-backed facts and build imagery-led videos even when the uploaded material contains little or no text.
- Redesigned website and file previews with cinematic film frames, consistent typography and responsive layouts.

## 0.1.9

- Manage your username, password and two-factor authentication on a clearer account page with improved desktop and mobile layouts and a visible two-factor status.

## 0.1.8

- Fixed website scanning on IPv4-only servers when a website also advertises IPv6.

## 0.1.7

- Updated image processing, AI workflow and connection libraries for reliability and security.
- Preserved compatibility when importing older projects after the checkpoint database update.

## 0.1.6

- View the update history from What’s new in the footer, available to everyone in the workspace.
- Enjoy a calmer AI provider page with a compact configuration summary and collapsible settings.
- Use consistent English role names throughout the interface: Director and Assistant director.
- Release notes now come from this change log, and releases stop early if their version has no entry.

## 0.1.5

- See available updates directly on the Director’s desk.
- Find update actions, release notes and credential guidance more easily on the redesigned Updates page.

## 0.1.4
